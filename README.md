# オーディオファイル分析プログラム

このプログラムは、オーディオファイルを分析し、以下の特徴量を抽出します：
- テンポ
- MFCC（メル周波数ケプストラム係数）
- スペクトル重心
- ゼロ交差率
- 基本周波数（F0）
- クロマ特徴量

## 必要条件

- Python 3.8以上
- 必要なパッケージ（requirements.txtに記載）

## インストール方法

1. リポジトリをクローンまたはダウンロードします
2. 必要なパッケージをインストールします：
```bash
pip install -r requirements.txt
```

## 使用方法

コマンドラインから以下のように実行します：

```bash
python audio_analyzer.py <オーディオファイルのパス>
```

## 出力形式

プログラムは以下の形式で結果を出力します：

```
tempo: 92.3
mfcc_mean: [125.3, -44.1, 12.0, ...]
spectral_centroid_mean: 2360.5
zero_crossing_rate_mean: 0.019
f0_mean: 442.0
chroma_mean: [0.1, 0.2, ..., 0.05]
```

## 注意事項

- サポートされているオーディオフォーマット：WAV, MP3, OGG, FLAC
- 大きなファイルの処理には時間がかかる場合があります
